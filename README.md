## About

This module introduces the philosophy and purpose of Test-Driven Development (TDD). Students will explore the benefits of TDD in improving code quality and development speed, compare it to other common testing strategies, and understand where TDD fits in a modern testing workflow. This prepares them to apply the TDD cycle in the next hands-on module.

## Content

| [Understanding Test-Driven Development](./understanding-test-driven-development/README.md) |       10 min       | Describe the purpose and key benefits of Test-Driven Development (TDD) in software development.      |
| [Creating Effective Unit Tests](./creating-effective-unit-tests/README.md)                 |       20 min       | Write a unit test to verify the behavior of a small, isolated function or component.                 |
